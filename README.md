# 교실 도구 (교사용)

초등학교 교사가 수업 중에 쓰는 Windows 데스크톱 앱입니다. 로그인, 서버, 인터넷 연결 없이 동작합니다.

- **큰 글씨 칠판**: 키보드로 입력한 문구를 크게 표시합니다.
- **타이머**: 수동 타이머와 예약 타이머가 있습니다. 칠판과 타이머를 함께 보거나 타이머만 전체 화면으로 볼 수 있습니다.
- **랜덤 자리 배치**: 짝꿍형과 개인형을 지원하고, 교사만 아는 숨겨진 고정 자리를 둘 수 있습니다.
- **랜덤 발표자 뽑기**: 중복 없이 뽑거나 매번 전체에서 뽑을 수 있습니다.

교사용 창(1번 모니터)과 학생용 창(TV·프로젝터)이 **별도 창**으로 동작합니다.

---

## 1. 빠른 사용 설명

### 설치
1. 저장소 페이지 오른쪽 **Releases**에서 최신 버전의 `ClassroomTools-Setup-x.x.x.exe`를 내려받아 실행합니다.
   - 설치 파일은 GitHub Actions가 Windows에서 자동으로 빌드합니다 (`.github/workflows/release.yml`).
   - 코드 서명이 없는 설치 파일이라 Windows SmartScreen 경고가 나올 수 있습니다. 이때는 **추가 정보 → 실행**을 누르세요.
2. 바탕 화면이나 시작 메뉴의 **교실 도구**를 실행합니다.

### 처음 설정 (5분)
1. **학생 명단**: 엑셀에서 `번호·이름(·성별)` 열을 복사해 붙여넣고 **기존 명단에 추가**를 누릅니다. 이름만 한 줄에 하나씩 적어도 됩니다. 성별(남/여)은 표에서 버튼으로도 고칠 수 있습니다.
2. **설정 → 학생용 화면 출력**: TV·프로젝터 디스플레이를 고릅니다.
   - Windows 디스플레이 설정은 **확장** 모드여야 합니다.
   - 모니터 하나로 시험해 볼 때는 **미리보기 창 열기**를 쓰세요.
3. 반이 여러 개라면 **학생 명단 → 학급 추가**로 학급을 만들고, 위쪽 학급 선택 상자에서 바꿉니다.

### 기능별 사용법
| 기능 | 사용법 |
|---|---|
| 칠판 | 문구를 입력하고 **학생 화면에 표시**를 누릅니다. 누르기 전까지 편집 중인 문장은 학생에게 보이지 않으며, 입력 내용은 자동 저장됩니다. **실시간 반영 켜기**를 누르면 그때부터 입력하는 내용이 바로 학생 화면 칠판에 보입니다 (예약 타이머가 뜰 때도 최신 내용으로 표시). |
| 타이머 | 1·3·5·10분 바로가기를 누르거나 분·초를 입력한 뒤 **시작**을 누릅니다. **종료 예고음**(3분·1분·30초·10초 전부터)을 고르면 그때부터 끝날 때까지 1초마다 째깍 소리가 나고, 마지막 10초는 높은 소리로 바뀝니다. 예약마다 따로 정할 수 있습니다. 표시 방식은 **칠판 + 타이머 함께 보기**(기본)와 **전체 화면 타이머** 중에서 고르며, 진행 중에도 바꿀 수 있습니다. |
| 예약 | 예: 매주 월~금 10:20 · 5분 · 쉬는 시간. 해당 시각에 숨겨져 있던 학생 화면이 TV에 나타나고 타이머가 자동으로 시작됩니다. 표시 방식은 두 개의 미리보기 그림(칠판 + 타이머 / 전체 화면 타이머) 중 하나를 눌러 고르며, 그림은 지금 학생 화면에 표시된 칠판 내용으로 실제 모습을 보여 줍니다. |
| 자리 배치 | 자리 모양은 **짝꿍형**, **개인형**, **분단별 설정** 중에서 고릅니다. 분단별 설정에서는 분단마다 한 줄 인원(1~4명)과 줄 수를 따로 정합니다 (예: 1분단 2명, 2분단 3명). **남자 / 여자 자리** 상태에서 자리를 누르거나 ‘짝마다 왼쪽 남 · 오른쪽 여’ 같은 버튼으로 남녀 자리를 정하면, 남학생은 남자 자리, 여학생은 여자 자리에 무작위로 앉습니다. 학생 성별은 학생 명단에서 입력합니다. 그다음 자리 모양을 정하고, **🔒 학생 고정하기** 상태에서 자리를 눌러 학생을 고정합니다. 이어서 **미리 추첨**(교사만 봄) 후 **학생 화면에 공개**하거나, **바로 추첨·공개**를 누릅니다. 결과는 **확정**하거나 저장할 수 있습니다. |
| 발표 뽑기 | 인원과 방식을 고르고 **뽑기**를 누릅니다. 오늘 추첨 기록과 남은 학생을 확인할 수 있습니다. |

### 바탕화면 위젯 (구글 캘린더)
- 교사용 모니터 바탕화면에 **달력 · 일정 정리 · 메모 · 시계·교시 · 날씨·미세먼지 · 급식 · 이번 주 시간표 · 수업 도구** 칸이 있는 보드를 띄웁니다. **Ctrl+Alt+W**로 보이기·숨기기, 알림 영역 메뉴에서도 켤 수 있습니다.
- **구글 캘린더 연결**: 교사용 화면 **위젯 → 구글 캘린더 연결**에 구글 캘린더 설정의 **‘iCal 형식의 비공개 주소’**를 붙여넣습니다. 로그인·인증키가 필요 없고, 15분마다 새로 받습니다.
  - 주소는 이 PC의 Windows 계정으로 암호화해 저장하며 화면에는 보내지 않습니다.
  - 일정 추가: 위젯 달력에서 날짜를 **두 번** 누르고 ‘구글 캘린더(브라우저에서 저장)’를 고르면 내용이 채워진 구글 캘린더 화면이 열리고 **저장**만 누르면 됩니다. ‘내 일정(이 PC)’에 바로 넣을 수도 있습니다.
- 대한민국 공휴일(대체공휴일 포함), 교시 시각(점심·**중간놀이** 포함), 날씨 지역(무료 Open-Meteo), 학교 급식(나이스, 인증키 없이)을 위젯 설정에서 정합니다. 인터넷이 끊기면 마지막으로 받은 정보를 보여 줍니다.

### 시간표
- **위젯 탭 → 이번 주 시간표**에서 월~금 × 교시 칸에 과목을 적거나, 엑셀·한글의 시간표 표를 복사해 **붙여넣기**로 한 번에 채웁니다(요일 머리글·교시 번호 칸은 자동으로 건너뜀).
- **오늘 시간표**는 이 표에서 오늘 요일 줄을 그대로 가져와 학생용 위젯의 ‘오늘 시간표’에 보여 줍니다. 시계 칸에는 과목을 표시하지 않고 교시만 보입니다.

### 학생용 위젯 (학생 화면)
- 교사용 위젯 위쪽 **📺 학생 위젯 띄우기**, 오른쪽 미리보기 아래 **학생 위젯** 버튼, 또는 **위젯 탭 → 학생용 위젯**에서 띄웁니다.
- 왼쪽 큰 칸에 평소에는 **큰 시계와 지금 교시·남은 시간·다음 교시**가 보입니다. 오른쪽에는 달력(공휴일만), 날씨, 급식, 이번 주 시간표가 있고, 아래에는 오늘 시간표와 **알림장**(위젯 탭에서 입력)이 있습니다.
- 학생용 위젯을 띄운 채로 **칠판을 표시하거나 타이머를 시작하면** 큰 시계 자리에 **칠판 / 타이머 / 칠판+타이머**가 대신 뜹니다. 타이머를 닫으면 그 전 화면으로 돌아가고, **큰 칸: 시계**를 누르면 시계로 돌아갑니다.
- **보일 칸**: 위젯 탭 → 학생용 위젯에서 달력·날씨·급식·이번 주 시간표·오늘 시간표·알림장을 체크로 켜고 끕니다(큰 시계 칸은 항상 보임). 끈 칸 자리는 남은 칸이 채웁니다.
- 학생용 위젯에는 **구글 캘린더·내 일정·메모가 나오지 않습니다**.

### 알아 둘 점
- **학생 화면 보이기**를 누르면 학생 화면이 2번 디스플레이에 **다른 창보다 항상 위에** 표시됩니다.
  - **학생 화면 숨기기**를 누르면 학생 화면이 내려가(숨김) 그 디스플레이의 다른 창이 다시 보입니다.
  - 이 동작은 **설정 → 학생 화면을 다른 창보다 항상 위에 표시**에서 끌 수 있습니다. 꺼 두면 타이머가 표시되는 동안에만 맨 위에 올라옵니다.
- **모니터가 하나뿐일 때**(또는 학생 화면이 교사용 모니터에 떠 있을 때) 학생 화면이 화면을 덮고 있으면 **Esc** 키를 누르세요. 학생 화면이 숨겨지고 교사용 창으로 돌아옵니다.
  - 학생용 TV에 따로 떠 있을 때는 실수로 꺼지지 않도록 Esc가 동작하지 않습니다.
  - 학생 화면에서 마우스를 2초 동안 움직이지 않으면 커서가 숨겨지고, 움직이면 다시 보입니다.
- 창의 **✕를 눌러도 앱은 꺼지지 않고** 알림 영역(화면 오른쪽 아래)에서 예약을 감시합니다.
  - 처음 닫을 때 한 번 안내가 나옵니다.
  - 완전히 끄려면 알림 영역 아이콘을 오른쪽 클릭한 뒤 **앱 완전 종료**를 선택합니다.
- **앱을 완전히 종료했거나 PC가 꺼져 있거나 절전 중이면 예약이 실행되지 않습니다.**
  - 그동안 놓친 예약은 다시 켰을 때 한꺼번에 실행하지 않습니다.
  - 대신 **예약 → 실행 기록**에 ‘놓침’으로 남습니다.
- 타이머 종료 알림음은 Windows의 **기본 출력 장치**로 나옵니다. TV 스피커로 들으려면 Windows 소리 설정에서 출력 장치를 바꾸세요.
- 데이터 저장 위치는 `%APPDATA%\ClassroomTools\classroom-data.json`입니다.
  - 백업 파일(`classroom-data.backup.json`)도 자동으로 만들어집니다.
  - **설정 → 데이터 내보내기·가져오기**로 다른 PC에 옮길 수 있습니다.
  - 앱을 제거해도 데이터는 지워지지 않습니다.
- **Windows 시작 시 자동 실행**은 기본으로 꺼져 있습니다. 켜면 알림 영역에서 조용히 시작합니다.

### 업데이트
- **설정 → 업데이트 → 업데이트 확인**을 누르면 GitHub에 올라온 최신 버전을 확인합니다 (인터넷 필요).
- 새 버전이 있으면 **업데이트 설치**를 누릅니다. 설치 파일을 내려받아 손상 여부(SHA-256)를 확인한 뒤 조용히 설치하고 앱을 다시 켭니다.
- 앱을 켤 때도 한 번 자동으로 확인해서, 새 버전이 있으면 왼쪽 **설정**에 ‘새 버전’ 표시가 나옵니다.
- 학급·명단·예약 등 데이터는 그대로 유지됩니다. 설치 후 앱이 다시 켜지지 않으면 바탕 화면의 **교실 도구** 아이콘으로 실행하세요.

### 예약이 실행되지 않을 때
1. **예약 → 실행 기록**을 확인합니다.
   - ‘놓침’이 있으면 그 시각에 앱이 꺼져 있었거나 PC가 절전 상태였던 것입니다.
   - ‘화면 없음’이 있으면 타이머는 시작됐지만 학생용 디스플레이를 찾지 못한 것입니다. **설정**에서 TV를 다시 선택하세요.
2. 예약 화면 위쪽의 **이 PC의 현재 시각**이 실제 시각과 맞는지 확인합니다. 예약은 이 시각을 기준으로 실행됩니다.
3. 예약 시각에 앱이 실행 중이어야 합니다. 알림 영역(화면 오른쪽 아래 ^)에 교실 도구 아이콘이 있는지 확인하세요.
4. 그래도 안 되면 **예약 → 진단 기록 열기**로 `schedule-log.txt`를 열어 내용을 알려 주세요.
   - 이 파일에는 앱 시작, 예약 실행·놓침, 학생 창 표시 결과, 절전 진입·복귀가 시각과 함께 기록됩니다.

다른 AI(GPT 등)나 개발자에게 비판적 검토를 맡길 때는 `docs/REVIEW_GUIDE.md`(안내서)와 `docs/GPT_REVIEW_PROMPT.md`(요청문)를 쓰고, `npm run review-bundle`로 만든 `review-bundle/` 파일을 첨부합니다.

## 2. 기술 선택

**Electron + TypeScript + React**를 사용하고, esbuild로 번들링하며, electron-builder로 NSIS 설치 파일을 만듭니다.

- 이 요구사항에 필요한 OS 기능을 Electron이 안정적으로 제공합니다.
  - 여러 디스플레이 감지와 연결·해제 이벤트 (`screen`)
  - 포커스를 빼앗지 않는 창 표시 (`showInactive`)
  - 다른 창 위에 표시 (`setAlwaysOnTop`)
  - 알림 영역 (`Tray`)
  - 절전 복귀 감지 (`powerMonitor`)
  - 중복 실행 방지 (`requestSingleInstanceLock`)
  - 자동 실행 (`setLoginItemSettings`)
- Tauri는 설치 파일이 작다는 장점이 있습니다. 하지만 위 기능 중 일부(특히 포커스 없는 표시, 디스플레이 이벤트)를 Rust로 직접 구현해야 해서 검증 부담이 큽니다. 그래서 Electron을 선택했습니다.

## 3. 구조

```
src/
  shared/          # 화면과 무관한 핵심 로직 (자동 테스트 대상)
    types.ts       #   데이터 구조
    seating.ts     #   좌석 생성, 고정 자리 검증, 무작위 배치 알고리즘
    picker.ts      #   발표자 추첨
    schedule.ts    #   다음 실행 시각, 실행/놓침 판정, 충돌 검사
    timer.ts       #   종료 시각 기반 타이머 상태 전이
    roster.ts      #   명단 붙여넣기 해석, 동명이인 표시, 결석 판정
    studentView.ts #   학생 화면용 데이터 (교사용 정보 제거)
    displays.ts    #   학생용 디스플레이 선택·재연결
    defaults.ts    #   기본값, 저장 데이터 정규화, 가져오기 검증
  main/            # Electron 메인 프로세스
    main.ts        #   창·디스플레이·알림 영역·IPC·예약 감시 루프
    controller.ts  #   앱 상태의 단일 원본, 모든 동작 처리
    store.ts       #   JSON 저장 (원자적 쓰기 + 백업)
  preload/         # 교사용(동작 가능) / 학생용(표시 데이터 구독만) 분리
  renderer/
    common/        # 학생 화면 렌더링 (학생 창과 교사용 미리보기가 공유)
    teacher/       # 교사용 화면 (탭별 컴포넌트)
    student/       # 학생 창
tests/             # 핵심 로직 자동 테스트 (Vitest)
tests-e2e/         # 실제 앱 E2E 테스트 (Playwright + Electron)
scripts/           # 빌드, 아이콘 생성, Linux에서 Windows 설치 파일 빌드
```

### 주요 설계
- **상태는 메인 프로세스에만** 있습니다.
  - 교사 화면은 동작을 요청하고(`dispatch`) 전체 상태를 받습니다.
  - 학생 창은 `buildStudentView()`가 만든 **표시용 데이터만** 받습니다. 이 데이터에는 이름 문자열, 좌석 위치, 칠판 공개본, 타이머 값만 들어 있습니다.
  - 학생 ID, 고정 여부, 결석 정보, 편집 중인 칠판 문구는 학생 창으로 전달되지 않습니다.
- **고정 자리 배치 알고리즘** (`seating.ts`의 `drawSeating`):
  1. 사용할 좌석과 참여 학생을 확정합니다.
  2. 유효한 고정을 먼저 배정합니다.
  3. 나머지 학생을 Fisher–Yates 셔플(암호학적 난수, 거부 샘플링)로 남은 좌석에 배정합니다.
  4. 중복·누락을 검증합니다.

  화면에서 이름을 덮어쓰는 방식은 쓰지 않습니다. 학생 화면은 모든 좌석이 같은 섞기 연출 후 **동시에** 같은 효과로 공개됩니다.
- **타이머**는 `endAt`(종료 시각)만 저장하고 남은 시간은 `endAt - 현재 시각`으로 계산합니다. 그래서 최소화나 지연이 있어도 느려지지 않습니다.
- **예약 감시**는 창과 무관하게 메인 프로세스에서 0.25초마다 판정합니다.
  - 각 예약의 마지막 처리 발생 키(`scheduleFired`)로 중복 실행을 막습니다.
  - 2분보다 오래 지난 발생은 실행하지 않고 ‘놓침’으로 기록합니다.
  - 절전 복귀(`resume`) 때도 즉시 판정합니다.
- **칠판 + 타이머 함께 보기**: 오른쪽 아래 1/4(가로 50% × 세로 50%)은 타이머 전용 영역입니다.
  - 칠판 문구는 ‘위쪽 절반 띠’와 ‘왼쪽 절반 띠’ 중 글씨가 더 크게 들어가는 쪽에 배치합니다.
  - 넘칠 때는 글자 크기를 줄이고 줄을 바꿀 뿐, 문구를 자르지 않습니다.

## 5. 검증 결과

### 자동 테스트로 확인한 항목 (`npm test`, 69개 통과)
- 5명, 7·13·23·29명(홀수), 30명 자리 배치를 짝꿍형·개인형 각각에서 확인했습니다 (회당 50번 반복). 학생 중복·누락이 없었고 사용 안 함 좌석에는 배정되지 않았습니다.
- 짝꿍형 ↔ 개인형 전환: 사라지는 좌석의 고정은 충돌로 보고하고, 유효한 고정은 유지됩니다.
- 고정 학생은 200번 반복해도 항상 지정 좌석에 배정됩니다. 나머지 학생 배치는 카이제곱 검정으로 편향이 없음을 확인했습니다.
- 같은 학생을 여러 좌석에, 또는 같은 좌석에 여러 학생을 지정하는 것을 막습니다.
- 좌석 부족(사용 안 함 좌석 포함)은 실행 전에 안내합니다. 결석으로 인원이 줄면 부족 상태가 풀립니다.
- 동명이인은 ID로 구분되고 화면에는 ‘이름(번호)’로 표시됩니다.
- 결석·제외된 고정 학생은 배치에서 빠지고 고정 설정은 유지됩니다.
- 중복 없는 발표 추첨에서는 전원이 한 번씩 뽑히고, 완료 안내 후 자동으로 다시 포함하지 않습니다. 남은 인원보다 많이 요청하면 안내합니다. 전체 모드에서는 한 회차 안에 중복이 없습니다.
- 반복 예약의 다음 실행 시각: 평일, 주말, 금요일 다음 월요일, 연말을 넘기는 경우, 한 번 실행을 확인했습니다.
- 예약 중복 실행 방지: 1초 간격으로 판정해도 한 번만 실행됩니다.
- 절전 복귀 때 오래된 예약은 놓침으로 기록하고 실행하지 않습니다. 2분 이내 지연은 실행합니다. 시계를 뒤로 돌려도 안전합니다.
- 같은 시각 예약 충돌(반복끼리, 한 번 실행과 반복 사이)을 검사합니다.
- 타이머: 일시정지·계속·초기화, 갱신이 지연되어도 정확한 남은 시간, 종료 알림 1회, 표시 방식을 바꿔도 시간이 유지됩니다.
- 학생 화면 데이터에는 고정 정보, 학생 ID, 결석 정보, 편집 중인 문구가 포함되지 않습니다.
- 저장 후 다시 읽으면 데이터가 같습니다. 손상된 값은 기본값으로 바뀌고, 잘못된 가져오기 파일은 거부합니다.

### 실제 앱으로 확인한 항목 (`npm run e2e`, 22개 통과 · Linux 가상 화면)
- 단일 모니터일 때 학생 창을 교사 화면에 띄우지 않습니다.
- 엑셀 형식 명단 붙여넣기(동명이인 포함 23명)가 동작합니다.
- 편집 중인 칠판 문구는 학생 화면에 나가지 않고, ‘표시’를 누르면 TV 쪽 창에 나타납니다.
- 교사 UI로 학생을 고정한 뒤 공개해도, 학생 화면 텍스트·클래스·속성에 고정 표시가 없고 모든 좌석 스타일이 같습니다. 고정 학생은 지정 좌석에 앉습니다.
- 미리 추첨 결과는 학생 화면에 보이지 않고, ‘공개’를 눌러야 같은 결과가 표시됩니다.
- **교사 창을 알림 영역에 숨기고 학생 창도 숨긴 상태에서** 예약 시각이 되면 다음과 같이 동작합니다.
  - 학생 창이 TV 위치에 칠판 + 타이머로 나타나고, 맨 위에 고정됩니다.
  - 교사 창은 계속 숨겨져 있습니다.
  - 포커스를 가져가는 호출(`show`·`focus`)은 일어나지 않고 `showInactive`만 쓰입니다.
- 긴 칠판 문구가 타이머와 겹치거나 잘리지 않습니다. 1280×720, 1024×768, 1366×768, 1920×1200 해상도와 150% 확대에서도 마찬가지입니다.
- 타이머가 끝나면 종료 화면이 유지되고, 알림음은 메인·화면 모두에서 정확히 1회 재생됩니다. 같은 예약은 한 번만 실행됩니다.
- 종료 화면을 닫으면 이전 칠판 전체 화면으로 돌아가고 맨 위 고정이 해제됩니다.
- 일시정지 중에 표시 방식을 바꿔도 남은 시간이 그대로 유지됩니다.
- 발표자 3명 뽑기가 학생 화면에 표시되고, 남은 인원이 맞게 표시됩니다.
- 디스플레이 연결 해제·재연결 (Electron screen API를 가짜 디스플레이로 바꿔 흉내 냄):
  - 해제하면 학생 창을 숨기고 안내합니다. 교사 화면에 전체 화면으로 띄우지 않습니다.
  - 재연결하면 TV 위치에 다시 표시합니다.
- 앱을 재시작해도 명단, 칠판, 예약, 고정 자리, 확정 배치가 복원됩니다.
- 두 번째로 실행하면 바로 종료됩니다 (중복 실행 방지).
- 패키징된 앱(asar)이 실행되고 아이콘·데이터 경로가 정상임을 Linux 패키지로 확인했습니다.

스크린샷: `tests-e2e/screenshots/`

### 이 환경에서 확인하지 못한 항목 — Windows PC에서 직접 확인이 필요합니다
빌드는 Linux에서 했고, Windows에서 실행해 보지는 못했습니다. 아래 절차로 확인해 주세요.

1. **설치·실행**: 설치 파일을 실행 → 바로 가기 생성 → 앱 실행 → 제거 프로그램 동작까지 확인합니다.
2. **실제 듀얼 모니터**: Windows 디스플레이 설정을 ‘확장’으로 둡니다.
   - 설정에서 TV를 선택하고 ‘학생 화면 보이기’를 누릅니다. TV에 전체 화면으로 표시되고 작업 표시줄이 가리지 않는지 봅니다.
   - 창 모드로 바꿔도 잘 보이는지 봅니다.
3. **예약 + 포커스**: 2분 뒤 예약을 만들고 교사 창 ✕(알림 영역)를 누릅니다. 메모장에 글을 계속 입력하면서 예약 시각을 기다립니다.
   - TV에 타이머가 뜨는지 봅니다.
   - 메모장 입력이 끊기지 않는지(포커스 유지) 봅니다.
   - TV 쪽으로 다른 창을 끌어 놓아도 타이머가 위에 보이는지 봅니다.
   - 타이머를 닫은 뒤에는 다른 창이 학생 화면 위로 올라올 수 있는지 봅니다.
4. **최소화 상태**: 교사 창을 최소화(—)한 상태에서 3번을 반복합니다.
5. **절전 복귀**: 예약 1분 전에 PC를 절전 상태로 둡니다. 예약 시각에서 5분 이상 지난 뒤 깨웁니다.
   - 타이머가 실행되지 **않아야** 합니다.
   - ‘예약 → 실행 기록’에 ‘놓침’이 있어야 합니다.
6. **디스플레이 케이블 분리·재연결**: 학생 화면이 표시된 상태에서 HDMI를 뽑습니다.
   - 교사 모니터에 학생 화면이 전체 화면으로 뜨지 않는지 봅니다.
   - 안내 문구가 나오는지 봅니다.
   - 다시 꽂으면 TV에 다시 표시되는지 봅니다.
7. **화면 배율**: Windows 배율 125%·150%와 TV 해상도 1366×768·4K에서 칠판 + 타이머 함께 보기와 자리 배치 이름이 잘리지 않는지 봅니다.
8. **알림음**: 미리 듣기와 종료 시 1회 재생을 확인합니다. 무음·음량 0이면 소리가 나지 않아야 합니다.
9. **알림 영역**: 처음 ✕를 누를 때 안내 창이 한 번만 나오는지 봅니다. 아이콘 메뉴의 ‘교사용 화면 열기’와 ‘앱 완전 종료’를 확인합니다.
10. **자동 실행**: 설정에서 켠 뒤 재부팅하면 알림 영역에서 시작되는지 봅니다. 기본값이 꺼짐인지도 확인합니다.
11. **중복 실행**: 바로 가기를 두 번 눌러도 창이 하나만 뜨고 예약이 두 번 실행되지 않는지 봅니다.
12. **데이터 내보내기·가져오기**: 다른 PC에서 가져오기 → 덮어쓰기 확인 창 → 복원까지 확인합니다.

### 알려진 제한
- 진행 중이던 타이머는 앱을 완전히 종료하면 이어지지 않습니다. 명단·설정·예약 등 데이터는 모두 저장됩니다.
- 설치 파일에 코드 서명이 없어 SmartScreen 경고가 나올 수 있습니다.
- 전체 화면 전환 때 Windows가 포커스를 옮기는지는 위 3번 절차로 확인해야 합니다.
  - 앱은 항상 `showInactive`로 학생 창을 띄우고 교사 창에는 포커스 관련 호출을 하지 않습니다.
