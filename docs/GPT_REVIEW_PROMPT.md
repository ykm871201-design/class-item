# GPT에 붙여넣을 검토 요청문

아래 ‘---’ 사이의 글을 그대로 복사해 붙여넣으세요. 소스는 첨부 파일(review-bundle) 또는 저장소 주소로 함께 줍니다.

---

당신은 Electron·TypeScript 데스크톱 앱과 교실용 소프트웨어를 많이 검토해 본 시니어 개발자입니다. 첨부한 프로그램을 **비판적으로 검토**해 주세요. 칭찬보다 **실제로 문제가 될 수 있는 점**을 찾는 것이 목적입니다.

**자료**
- `00-guide.md`(또는 docs/REVIEW_GUIDE.md)를 먼저 읽으세요. 목적, 구조, 꼭 지켜야 할 요구사항, 작성자가 이미 아는 약점이 있습니다.
- 나머지 파일에 전체 소스와 테스트가 줄 번호와 함께 들어 있습니다.
- 저장소: https://github.com/ykm871201-design/class-item

**검토 순서 (위쪽이 더 중요)**
1. **정확성**: 예약 타이머가 정시에 정확히 한 번 실행되는가(절전 복귀·시계 변경·앱 재시작·같은 시각 예약), 타이머·예고음, 자리 배치의 중복·누락·편향(고정 자리·남녀 자리·분단별), 뽑기, iCal 해석, 교시 계산.
2. **학생 화면 정보 누출**: 고정 자리·남녀 자리·학생 ID·결석 정보·편집 중 문구·구글 캘린더·개인 메모가 학생 창(데이터나 DOM)으로 갈 수 있는 경로가 있는가.
3. **보안**: Electron 설정(contextIsolation·sandbox·preload에 드러난 API·CSP·탐색 제한), IPC 입력 검증, 업데이트(다운로드·검증·조용한 설치)의 공격 가능성, 외부 요청.
4. **데이터 안전**: 저장 중 손상, 옛 버전·손상 파일 복원(normalizeData), 가져오기, 개인정보(학생 명단 평문 저장 등).
5. **Windows 실제 환경 위험**: 듀얼 모니터, 포커스, 맨 위 표시, 디스플레이 분리, 배율, 업데이트 후 재실행. 코드만 보고 판단할 수 있는 범위에서.
6. **성능·자원**: 전체 상태 브로드캐스트, 250ms tick, 렌더링, 메모리 누수 가능성.
7. **유지보수성**: 구조, 타입 안전성, 중복, 테스트가 빠뜨린 중요한 경우.
8. **교실 사용성**: 수업 중 실수하기 쉬운 곳, 학생 화면 가독성.

**결과 형식**
- 발견한 문제마다 다음을 적어 주세요.
  - **심각도**: 치명 / 높음 / 보통 / 낮음
  - **확실성**: 확실(코드로 증명 가능) / 추정(실행해 봐야 앎)
  - **위치**: `파일:줄`
  - **문제**: 무엇이 잘못되었나
  - **실제로 언제 문제가 되나**: 교실에서 일어날 구체적인 상황이나 재현 순서
  - **근거**: 해당 코드 몇 줄 인용
  - **고치는 방법**: 짧게, 가능하면 코드로
- 심각도 순으로 정렬해 주세요.
- 안내서 4절 ‘이미 아는 약점’에 있는 것은 **새로운 근거나 더 나쁜 결과**를 찾았을 때만 다시 적어 주세요.
- 코드에 없는 기능이나 동작을 짐작해서 쓰지 마세요. 모르면 “확인 필요”라고 적어 주세요.
- 들여쓰기·이름 짓기 같은 단순 스타일 지적은 빼 주세요.
- 마지막에 **먼저 고칠 5가지**와, 잘 되어 있어 **바꾸지 말아야 할 점**(짧게)을 정리해 주세요.
- 한국어로 답해 주세요.

## 사용 방법

**방법 1 — 파일 올리기 (ChatGPT)**
1. `review-bundle` 폴더의 파일을 모두 첨부합니다 (`00-guide.md` ~ `04-tests.md`). 한 파일이 편하면 `classroom-tools-review-all.md` 하나만 올려도 됩니다.
2. 위 요청문을 붙여넣습니다.
3. 답이 길어 끊기면 “이어서”라고 하거나 “2번(학생 화면 정보 누출)만 더 깊게”처럼 범위를 좁혀 다시 요청하세요.

**방법 2 — 저장소 연결**
ChatGPT에서 GitHub를 연결할 수 있으면 저장소 `ykm871201-design/class-item`을 연결하고 요청문을 붙여넣습니다.

**받은 검토 결과는** 그대로 Claude에게 붙여넣고 “이 검토 결과를 확인해서 맞는 것만 고쳐 줘”라고 하면 됩니다. 검토 내용 중에는 틀린 지적도 있을 수 있으니 하나씩 확인한 뒤 고칩니다.
