## 권고 사항 반영 (결함 수에는 넣지 않은 항목)
- **IPC 보낸 창 확인**: `state:get`·`dispatch`·`app`·`dialog:confirm`은 교사용 창·위젯 창에서 온 요청만, `student:escape`는 학생 창에서 온 요청만 받음.
- **창 이동 금지**: 모든 창에서 다른 페이지로 이동(`will-navigate`)과 새 창 열기를 막음 (위젯의 외부 링크는 기본 브라우저로 엶).

## 여전히 남은 것 (검토서도 ‘판단 불가’로 둔 것)
실제 Windows에서의 전체 화면·포커스·HDMI 분리·배율·절전 복귀·업데이트 재실행은 아직 실측하지 않았습니다. 학생 명단 평문 저장, 코드 서명 없음, 전체 상태 브로드캐스트, 큰 dispatch switch도 그대로입니다 (`REVIEW_GUIDE.md` 4절).
